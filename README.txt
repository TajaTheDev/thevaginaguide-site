THE VAGINA GUIDE: WEBSITE FILES
===============================

HOW TO PUT IT LIVE (Cloudflare Pages, free)
1. Unzip this folder on a computer.
2. Cloudflare dashboard -> Workers & Pages -> Create -> Pages -> "Upload assets".
3. Project name: thevaginaguide -> drag in the unzipped folder (the one containing index.html) -> Deploy.
4. Open the project -> Custom domains -> Set up a custom domain -> thevaginaguide.com (repeat for www.thevaginaguide.com).
5. To update later: project -> Create new deployment -> drag the folder in again.

THE ONE FILE YOU EDIT: assets/js/site.js (top section)
- forms.waitlist: paste the number of your 2nd Kit form (App Waitlist).
- checkout.bv / yeast / period: paste your Kit product links. Empty = "Coming soon".

PLACEHOLDERS STILL TO SWAP (search the files for "[")

- About: your story + optional reviewer
- Work With Me: partner logo strip
